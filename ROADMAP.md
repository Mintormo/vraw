# ROADMAP vraw

План развития проявщика (согласовано с Игорем). Устройство того, что уже
сделано, — в PROJECT.md. Пункты внутри разделов — по приоритету.

## В планах

**Связи между пунктами.** Неразрушающее редактирование (снимок состояния
+ сайдкары) — фундамент для браузера папки и пакетной обработки: без него
при переключении кадров правки терялись бы, а пакету неоткуда брать
настройки. Порядок: снимок состояния, история, сайдкары, браузер папки,
окно «Экспорт» и пакетный экспорт (сделано). Форматы экспорта независимы,
новые настройки вывода добавляются в окно «Экспорт» — пакет их получает
сам.

### Средний приоритет

- [ ] **Локальные правки: маски и градиентные фильтры** — идея 29.09.2026.
      Правки, которые действуют только на часть кадра.
  - **Устройство**: у кадра — список масок (EditState: история,
    сайдкар), у каждой — своя форма и свой набор правок: экспозиция,
    контраст, тени/света, насыщенность, (после «Баланса белого»)
    температура/оттенок, (после «Clarity») локальный контраст и резкость.
    Результат — смешение: `out = mix(глобальный, с правками маски,
    маска)`. Маска хранится описанием (штрихи, параметры, щелчки), а не
    картинкой, и растеризуется под размер — превью и экспорт полного
    кадра дают одно и то же. Каждая маска — лишний проход пайплайна:
    держать превью в пределах ~150 мс, маску превью кэшировать.
  - **Умное выделение** (три уровня, по нарастанию сложности):
    1. **Диапазон** — по яркости и/или цвету (оттенок ± допуск, пипетка
       на снимке), с мягкими краями: небо, кожа, листва — дёшево и
       предсказуемо.
    2. **Умная кисть** — кисть, которая держится краёв: мазок
       расширяется по похожим цветам и не переходит контрастную границу
       (заливка по сходству + управляемый фильтр / guided filter для
       уточнения края, как «Auto Mask» в Lightroom). Размер, мягкость,
       сила, ластик.
    3. **AI-выделение** через уже встроенный ONNX Runtime: «Выделить
       объект» / «Выделить небо» (модель сегментации) и выделение
       щелчком по объекту (MobileSAM / EfficientSAM — щелчок → маска).
       Проверить лицензии и размер моделей, качать их как модели
       шумодава. Маска AI хранится щелчками + id модели и
       пересчитывается; на полном кадре — ресайз маски превью с
       уточнением края по полному кадру (guided filter), а не прогон
       модели на 24 Мп.
  - **Уточнение маски**: растушёвка, расширить/сузить, инвертировать,
    сложить/вычесть/пересечь маски (например, градиент ∩ диапазон
    «только небо, не деревья»); показ маски цветной заливкой поверх
    снимка (клавиша), список масок с включением/выключением и
    переименованием.
  - **Градиентные фильтры** — частный случай маски, параметрический:
    - **Линейный** (градиентный ND-фильтр для неба): две линии на
      холсте — начало и конец перехода; перетаскивание, поворот за
      ручку, ширина перехода.
    - **Радиальный** (эллипс): центр, два радиуса, поворот, растушёвка,
      внутрь/наружу — осветлить объект или своя виньетка.
    - Оба можно ограничить диапазоном (яркость/цвет), как выше.
  - Опора готова (кадрирование, 30.09.2026): координаты масок — в долях
    кадра до обрезки и поворота (`Geom.point_to_source` /
    `source_to_point`), рисование поверх холста — `Canvas.on_overlay`,
    мышь — `ev.fx/fy`, как у рамки кадрирования (crop.v).

- [ ] **Сравнение снимков** — идея 27.09.2026. Два режима в меню «Вид».
  - **Два кадра рядом**: в области просмотра два снимка бок о бок (или
    один над другим для вертикальных) — например, выбрать лучший из
    серии. Второй кадр — выделенный в ленте (одиночный щелчок уже только
    выделяет, не открывает). Синхронный зум и панорама (одинаковый
    участок в обоих), переключение «какой редактируется» щелчком по
    половине; подписи имён и отметка активного. Второму кадру нужна своя
    загрузка превью с его правками из сайдкара (фоновый загрузчик уже
    есть — вторая копия `LoadJob`/буферов).
  - **До и после**: тот же кадр без правок и с правками. Варианты:
    бок о бок, разделитель-шторка (перетаскиваемая вертикальная линия:
    слева «до», справа «после»), переключение по удержанию клавиши
    (например, `\`). «До» — нейтральные настройки (как «Открыт файл»)
    или выбранная запись истории; «после» — текущее состояние. Дёшево:
    сырьё то же, нужен второй прогон `pipeline.apply` с другими Params
    во второй буфер холста.
  - Из vgui: два Canvas со связанными зумом/панорамой (события
    `set_zoom`/скролл одного переносить на другой) или один Canvas со
    своей отрисовкой шторки.
