# Модуль i18n/ — перевод интерфейса (08.10.2026)

Часть документации vraw. Оглавление — [PROJECT.md](../PROJECT.md).

С 09.10.2026 — **обёртка над `vgui.i18n`** (подмодуль vgui на чистом V,
без SDL; устройство — PROJECT.md vgui, «Перевод интерфейса»). В vraw
осталось своё: вшитые `lang/*.json` (`embedded` — загрузчик для
`core.set_loader`), `set` (исходный язык ru, запасной en, незнакомый —
en), прежние имена функций — их ищут код и `tools/i18n_check.py`.
Каталог у vraw и vgui общий: `vgui.set_locale(i18n.current())` в `main`
добавляет строки vgui. Язык системы — `system_lang()` (settings.v):
`vgui.detect_system_locale()` (переменные окружения, иначе предпочтения
ОС через SDL) → `i18n.supported`; в самой обёртке SDL нет — её
импортируют `raw/`, `imgio/`, `lens/` (их тесты собираются за
3–4 с, без vgui). Правила форм числа и их тест — в vgui.

Ключ перевода — сама русская строка из кода (как в gettext):
`i18n.tr('Экспозиция')`. Код остаётся читаемым, русский отдельным файлом
не нужен. Переводы — `i18n/lang/<код>.json` (`{"русская строка":
"перевод"}`, 30 языков), вшиты `$embed_file`. Язык выбирается один раз
при запуске (`i18n.set` в `main` до окна и потоков; `Settings.lang`, ''
— язык системы `system_lang()`), дальше
таблицы только читаются — `tr` безопасна из потоков (воркеры, ошибки
модулей). До `set` (тесты, константы) модуль сам (`fn init`) ставит
ядру исходный и текущий язык — русский: иначе `pl` брал правило
английского («8 группы»). Поиск: язык → английский → ключ (русский). Смена языка — в
«Настройки - Интерфейс», применяется после перезапуска (подпись об этом
сразу на выбранном языке — `tr_in`).

- `tr(s)`; `trf('Кадр {0} из {1}', a, b)` — подстановки; `tr_all(список)`;
  `trc('ББ', 'Оттенок')` — омоним (ключ «контекст::строка»: «Оттенок» —
  Hue в HSL и Tint в балансе белого); `pl(n, 'кадр|кадра|кадров')` —
  форма числа: в переводе формы своего языка через «|» в порядке
  `plural_index` (CLDR для целых: славянские 3, словенский 4, латышский —
  ноль/один/прочие, вьетнамский и индонезийский 1, остальные 2).
- **Константы не переводятся при объявлении** (V вычисляет их до `main`,
  язык ещё не выбран): массив названий остаётся русскими ключами, перевод
  — там, где показывается (`i18n.tr(wb_names[i])`,
  `set_items(i18n.tr_all(...))`).
- Шрифт Roboto (vgui) — латиница, кириллица, греческий, вьетнамский;
  языки с другими письменностями (CJK, арабский, деванагари...) требуют
  резервных шрифтов в vgui — не сделано.
- `tools/i18n_check.py` — ключи из кода (аргументы `i18n.tr/trf/pl/tr_in/
  trc`, русские строки в константах) против файлов: сколько не хватает,
  лишних, где подстановки `{0}`/`{name}` не совпали; `--keys` — все ключи,
  `--missing de` — чего нет в языке. **Новая строка интерфейса** — в
  `i18n.tr(...)` и перевод во все `lang/*.json` (иначе показывается
  английский, без него — русский). Тест `i18n/i18n_test.v`: каждый файл
  читается, число форм в нём — по правилу языка; перевод, омоним, `tr_in`.
- Ошибки модулей (`raw/`, `imgio/`, `lens/`) тоже через `i18n.tr`
  — они доходят до пользователя в уведомлениях.
- vgui: `create_app` зовёт `setlocale(LC_CTYPE, "")` — иначе SDL3 на X11
  не ставит `_NET_WM_NAME` для заголовка вне Latin-1 (вьетнамский) и
  оконный менеджер показывает кашу.
