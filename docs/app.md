# Приложение (корень проекта, module main)

Часть документации vraw. Оглавление — [PROJECT.md](../PROJECT.md).

vraw — одно GUI-приложение: исходники `module main` лежат в корне,
библиотечные модули `raw/`, `lens/`, `pipeline/`, `imgio/` — в
подпапках. Сборка
`~/soft/v/v -prod -cc gcc .` → `./vraw`; тесты — все
разом `~/soft/v/v -cc gcc test .` (рекурсивно, вместе с
тестами модулей). Консольной версии нет с 27.09.2026 (был `main.v` и
модуль `develop/` — проявка без vgui ради CLI; растворён в приложении).

**Портабельная сборка для Linux** (`tools/portable.sh`, 08.10.2026; с
17.10 по 19.10.2026 — ещё с моделью AI-шумодава и ONNX Runtime, +~90
МБ): `dist/vraw/` и архив `dist/vraw-linux-x86_64.tar.gz`. Внутри: `vraw` (-prod, RPATH
`$ORIGIN/lib` — `--disable-new-dtags`, чтобы путь действовал и на
зависимости зависимостей), `lib/` — все .so из `ldd`, кроме glibc,
libstdc++ и libgcc_s (своя копия ломала бы драйверы, которые SDL
подгружает из системы), `lensfun/` — база профилей (обновлённая из
`~/.local/share`), `LICENSE` (MIT), `licenses/` и сводка
`THIRD_PARTY.md`. Лицензии: библиотеки из apt — пакет по `dpkg -S` (с
архитектурой: у libjpeg есть и i386), текст `/usr/share/doc/<пакет>/
copyright` и общие тексты из `/usr/share/common-licenses`, на которые он
ссылается, ссылка на исходный пакет на Launchpad (для LGPL — исходники
именно этой версии); краткое имя лицензии — таблица `spdx` в скрипте
(новый пакет без записи — сборка останавливается). SDL3 (собран в
`/usr/local`), V, Boehm GC, stb, Roboto (OFL 1.1, версия 3), Lucide —
тексты в `tools/licenses/`. Mbed TLS в
бинарнике нет с 17.10.2026 — сеть ушла вместе со скачиванием; vgui — `LICENSE` из
его репозитория. vgui и шрифты вшиты в бинарник. Ограничение —
glibc не старее системы сборки (2.39, Ubuntu 24.04); для старых систем —
собирать в контейнере со старой Ubuntu (не сделано: нет прав на docker).
Проверка — запуск в `bwrap` с пустыми `/usr/local/lib`, базами lensfun и
`/dev/null` на месте системных копий библиотек из `lib/`: кадр
открывается, профиль объектива находится.

**Портабельная сборка для Windows** (`tools/windows.sh`, 09.10.2026): кросс-компиляция на Linux — `v -os windows -cc
x86_64-w64-mingw32-gcc-posix -subsystem windows` (posix-вариант MinGW —
ради libgomp; `-subsystem windows` — без окна консоли). Библиотеки —
готовые пакеты MSYS2 mingw64 (msvcrt, как MinGW из Ubuntu):
`tools/win_deps.py` разбирает базу репозитория, тянет SDL3, SDL3_ttf,
SDL3_image, LibRaw (0.22, на Linux 0.21 — сборка по заголовку, API тот
же), lensfun с зависимостями, сверяет SHA-256 и кладёт в
`~/soft/mingw64-vraw` (`include/`, `lib/` с библиотеками импорта,
`bin/` с DLL, `dlls.tsv` — DLL → пакет, `packages.tsv` — версия,
лицензия, исходный пакет). Итог — `dist/vraw-windows/` и
`dist/vraw-windows-x86_64.zip` (~12 МБ): `vraw.exe`, рядом 25 DLL
(обход `objdump -p` от exe, системные DLL не берутся; SDL3_image грузит
кодеки AVIF/JXL/… по требованию — они не нужны), `lensfun/`, лицензии
пакетов из `share/licenses/` и ссылки на исходные пакеты MSYS2 в
`THIRD_PARTY.md` (в обеих сборках — на английском; README в сборки не
кладётся).

**Логотип и иконка** (`assets/icon/`, 01.11.2026): буква V на тёмной
скруглённой плитке — левая ветвь из пикселей матрицы Байера (красный,
зелёный, синий — сырьё), правая — тёплая тоновая S-кривая (проявка).
Исходники — `vraw.svg` (основной) и `vraw-small.svg` (для 16–32 px:
три крупных пикселя, толстая кривая — иначе мелкие точки сливаются).
PNG 16…512 — растеризация SVG в 1024 px (headless Chrome) и уменьшение
PIL (LANCZOS): до 32 px из small, крупнее — из основного; `vraw.ico`
собран из тех же PNG (16–256). Окно: `win.set_icon_data($embed_file(
'assets/icon/vraw-256.png'))` в `app.v` сразу после `create_window`
(метод vgui добавлен для этого; файл рядом с бинарником не нужен).
vraw.exe: `tools/windows.sh` компилирует `vraw.rc` через
`x86_64-w64-mingw32-windres` в COFF-объект и отдаёт его линковщику в
`-ldflags` (проверка — секция `.rsrc` в `objdump -h`). Linux-сборка
кладёт `vraw.png` рядом с бинарником (для ярлыка). Проверено:
`_NET_WM_ICON` окна в Xephyr — 256×256, картинка верная.

Платформенные места кода (суффиксы `_nix.c.v` / `_windows.c.v`, V сам
берёт нужный): `bigbuf/os_*` — `mmap` / `VirtualAlloc`; `sys_*.c.v` —
свободная память (`/proc/meminfo` / `GlobalMemoryStatusEx`) и приоритет
потока экспорта (`setpriority` / `SetThreadPriority`: на Windows
приоритет не наследуется потоками LibRaw); `raw/open_*` — LibRaw
открывает файл по UTF-16 пути (`libraw_open_wfile`: char*-путь там в
кодировке ANSI, кириллица ломалась бы). Тоже ради путей: JPEG/PNG/BMP
stbi кодирует в память (`imgio/stbmem.v`, `stbi_write_*_to_func`), в
файл пишет `os` (он на Windows открывает файлы по UTF-16).
Проверено под Wine 9 (09.10.2026; на настоящей Windows — ещё нет, см.
ROADMAP): окно, открытие CR3 из папки с кириллицей, профиль объектива из
`lensfun/`, тесты `raw/`, `imgio/`, `bigbuf/`, экспорта, кадрирования
(собранные `-os windows` exe), запись JPEG/PNG/TIFF в кириллический путь.
Найденное: с LTO (`-flto`, его включает
`-prod`) MinGW собирает vraw.exe с пустым окном — нет панели, холста,
заглушки, при любом отрисовщике. Причина — ошибка V: трамплин
замыканий amd64 портит `xmm15`, а в Windows x64 этот регистр сохраняет
вызываемая функция (vlang/v#29822). `-fno-lto` лишь маскировал: без
LTO после кадрирования были пустые превью и гистограмма. Исправлено в V
(ветка `amd64 && windows` в `closure.c.v` берёт `xmm5`, PR vlang/v#29831
принят 14.10.2026): нужен V не старее этой даты; LTO включён. Заодно vgui теперь
перерисовывает окно целиком по `SDL_EVENT_RENDER_TARGETS_RESET`
(профилактика: Direct3D теряет текстуры при сбросе устройства; под Wine
не воспроизводилось). Баланс белого «как снято» у LibRaw
0.22 (Windows) немного другой, чем у 0.21 (Linux): IMG_0991 — 5900 K / 2
против 5600 K / 10. Как проверять: Xvfb `:99`, отдельный `WINEPREFIX`
в черновике, `wine vraw.exe Z:\путь\кадр.CR3`, снимок `xwd -root` →
`ffmpeg` в PNG; отладочная сборка — без `-subsystem windows` (иначе
вывод V некуда писать), `SDL_RENDER_DRIVER=software|opengl` — сравнить
отрисовщики.

Файлы: `app.v` — State, окно, панель, пересчёты, `main()`; `wb_ui.v` — секция «Баланс белого»; `history.v`
— EditState и история; `sidecar.v` — формат сайдкара и чтение/запись;
`sidecar_strokes.v` — таблица мазков кисти сайдкара v3;
`loader.v` — фоновое открытие кадра и камерная кривая; `post.v` —
доставка результатов фоновых потоков в главный поток без замыканий
(`post_result`, `report`); `workers.v` — хендлы фоновых потоков
(`Worker`, `Done`, `track`, `reap`, `wait_all`); `export.v` —
проявка полного кадра для экспорта (этапы, отмена); `export_setup.v` —
окно «Экспорт» перед запуском (кадры, папка, имя, формат, размер);
`batch.v` — пакетный экспорт; `rating.v` — отбор (звёзды, флажки,
фильтр ленты); `compare.v` — до/после, щелчок-увеличение, удержание «\» (`bind_ba_hold`);
`pair.v` — сравнение двух кадров (`pair_test.v`);
`export_ui.v` —
диалог экспорта с прогрессом; `browser.v` — лента кадров; `presets.v` —
копирование настроек и пресеты; `clipping.v` — показ пересветов и провалов;
`crop.v` — кадрирование и поворот (секция, режим на холсте);
`masks.v` — градиентные фильтры (секция, ручки, заливка маски);
`lens_ui.v` — ручная коррекция объектива (ползунки секции «Коррекция»);
`spots_ui.v` — удаление пятен (секция, режим на холсте, показ пыли;
`spots_test.v`);
`autotone.v` — автотон (подбор тона по гистограмме, `autotone_test.v`);
`histogram.v` — гистограмма панели: виды, зоны эквалайзера
(`histogram_test.v`); `value_field.v` — поле значения ползунка
(`vgui.NumberField`, `value_field_test.v`);
`settings.v`, `themes.v` — настройки программы и темы; `uiscale.v` —
масштаб интерфейса (`uiscale_test.v`); `dlgfit.v` — корень диалога с
прокруткой (`dialog_scroll`; размер — vgui); `settings_ui.v` —
окно настроек; `panel.v` — раскладка окна (разделы
панели, сторона панели и ленты, скрытие; `panel_test.v`); тесты —
`edit_test.v` (история, сайдкар, лента), `sidecar_strokes_test.v`
(сайдкар v3: мазки один раз, текущие настройки без истории), `presets_test.v` (группы,
вставка в сайдкар и в открытый кадр, файлы пресетов, импорт/экспорт, удаление, переименование),
`clipping_test.v` (подсветка клипа, треугольники, щелчки), `rating_test.v`
(фильтры, пометка в сайдкаре и быстрое чтение, старый формат, вставка
не теряет пометку, выделенные и открытый кадр, строки ленты и соседи,
«Переходить к следующему», шторка, увеличение в точку, клавиши в живом окне),
`export_test.v` (`tone_lut`,
этапы экспорта и их доли, отмена, обрезка путей, экспорт тестового CR3 в
полном размере: +1 EV светлее нейтральной), `crop_test.v` (размер на
выход, пропорции, сайдкар геометрии, группа копирования, экспорт CR3 с
поворотом 1:1 и 1000 px без пустых углов, геометрия миниатюры из
сайдкара, миниатюра CR3 1:1 с поворотом, поворот мышью снаружи рамки и
новая рамка с Ctrl, ручной ввод угла).
