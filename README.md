# vraw

Проявка RAW (CR3 и другие форматы, которые понимает LibRaw) в JPEG. Написано на V.
Два приложения: CLI-конвертер и GUI-проявщик на [vgui](../vgui-python) с
собственным тональным пайплайном.

## Зависимости

- компилятор V (`~/soft/v/v`)
- LibRaw: `sudo apt install libraw-dev`
- для GUI: модуль vgui — симлинк `~/.vmodules/vgui -> ~/projects/vgui-python/v/vgui`
  (уже создан) и библиотеки SDL3 в `/usr/local/lib`

## Сборка

```bash
cd ~/projects/vraw
~/soft/v/v .                                        # CLI  -> ./vraw
~/soft/v/v -cc gcc -enable-globals gui/ -o vraw-gui # GUI  -> ./vraw-gui
~/soft/v/v test raw/ pipeline/                      # тесты
```

## CLI

```bash
./vraw IMG_0001.CR3                          # рядом появится IMG_0001.jpg
./vraw IMG_0001.CR3 итог.jpg -q 95           # свой путь и качество
./vraw IMG_0001.CR3 превью.jpg --half        # половинный размер, быстро (~0.1 с)
./vraw IMG_0001.CR3 светлее.jpg --bright 1.3 # поднять яркость
```

CLI проявляет классическим путём LibRaw (8 бит, авто-яркость) — быстрый
конвертер без ручной тональной работы.

## GUI

```bash
./vraw-gui                # пустое окно, открыть файл кнопкой
./vraw-gui файл.CR3       # сразу открыть файл
```

- превью в `vgui.Canvas`: колесо — зум, средняя/правая кнопка — панорама;
- коррекция объектива по профилю lensfun: виньетирование, дисторсия и
  хроматические аберрации; профиль ищется по EXIF автоматически,
  включается чекбоксом; нужна библиотека `liblensfun1` и, для свежих
  объективов, обновлённая база в `~/.local/share/lensfun/updates/version_1`;
- ползунок «Пересветы» - работа LibRaw с передержкой (клип / без клипа /
  смешение / восстановление 3..9); перепроявляет превью (~0.1 с) при
  отпускании ползунка, зум сохраняется;
- кнопка «Авто» у экспозиции: медиана яркости кадра приводится
  к среднему серому;
- панель справа: экспозиция (EV), тени, контраст, насыщенность,
  тон-эквалайзер на 5 полос (чёрные/тени/средние/света/белые, EV),
  качество JPEG; тональные диапазоны ±4;
- у каждого ползунка кнопка «×» - сброс только этого параметра;
  кнопка «Сброс» возвращает всё сразу;
- все ползунки работают вживую: пайплайн применяется к превью на каждое
  движение (~50 мс на превью 3000x2000);
- RGB-гистограмма результата (сверху панели): каналы смешиваются аддитивно
  (R+G — жёлтый, все три — светло-серый);
- «Сохранить JPEG...» проявляет в полном размере тем же пайплайном -
  в фоне, окно и ползунки не замирают; готовность - в строке статуса.

## Структура

```
raw/       — модуль raw: обёртка LibRaw (Developer / DevParams / DevImage),
             режим linear16 (16 бит, линейная гамма) + тесты
lens/      — модуль lens: обёртка lensfun (виньетирование, дисторсия, TCA) + тест
pipeline/  — собственный тональный пайплайн по линейным 16-битным данным + тест
main.v     — CLI
gui/       — GUI-приложение на vgui
```

## Как это устроено

- C-структуры LibRaw объявлены частично (только используемые поля) с
  `@[typedef]` — раскладку C-компилятор берёт из `<libraw/libraw.h>`.
- `Developer.develop()` можно вызывать многократно: `libraw_unpack` — один раз,
  дальше только смена `params` + `dcraw_process`.
- GUI зовёт LibRaw один раз на файл (`linear16`: 16 бит, линейная гамма,
  без авто-яркости — только демозаика и камерный ББ), дальше вся тональная
  работа — модуль `pipeline`.
- Пайплайн (арифметика во f32, 16 бит — только формат исходника; сенсор
  Canon отдаёт 14 бит, так что запас есть):
  1. экспозиция — множитель `2^EV` в линейном пространстве;
  2. тени и тон-эквалайзер — множитель по *люме* (BT.709), а не по каналу,
     чтобы подъём теней не сдвигал цвет; маска теней `(1-t)^2`, эквалайзер —
     5 узлов по тоновой шкале с линейной интерполяцией;
  3. гамма 1/2.2 + контраст — S-кривая `v^a/(v^a+(1-v)^a)`, `a = 2^c`
     (гладкая, без клиппинга);
  4. насыщенность — смешение с люмой в тоновом пространстве;
  5. выход 8 бит (RGBA для холста или RGB для JPEG).
- Живость ползунков: шаги 1–3 сведены в две таблицы по 65536 записей
  (`mlut`: люма → множитель; `flut`: значение канала → тон 0..255),
  перестраиваются за миллисекунды; на пиксель остаются умножения и выборки.
  Превью 6 Мп проходит пайплайн за ~50 мс.
- Гистограмма — второй `vgui.Canvas` 256x100 (`stretch`, зум/панорама
  отключены), считается по 8-битному результату с шагом в 2 пикселя.
- JPEG пишет `stbi.stbi_write_jpg` из stdlib V. EXIF не переносится (TODO).

## Замеры (Canon R8, CR3 24 Мп)

- проявка LibRaw полного размера: ~0.6 с; половинного (превью): ~0.1 с
- пайплайн на превью 3000x2000: ~50 мс (живое обновление при перетаскивании)
